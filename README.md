# Yitao Ye - Personal homepage

Japanese (default), Chinese and English personal homepage and web CV.

Website: https://yipsilon2887.github.io/

## Editing

- `content.json`: homepage text, affiliation, interests and activities.
- `resume.json`: web CV research entries, awards and skills.
- `social.json`: contact links.
- `styles.css`: typography and layout.

Save text files as UTF-8. Run `python build.py` then `python validate.py`.
Commit and push to `main`; GitHub Pages publishes from the repository root.
Generated language pages should be updated through their source JSON files.
